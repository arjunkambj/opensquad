# P17 feedback pack — agency trial materials

Prepared by the P17 lane ahead of the agency trial and the V21 recording.
**Nothing in this directory has been sent, published or claimed.** Every file
is a draft awaiting the decisions listed at the bottom of
`plan/evidence/P17.md`.

| File | Status | Purpose |
|---|---|---|
| [invitation.md](invitation.md) | Draft, **not sent** | One concise invite for a single real agency user |
| [trial-script.md](trial-script.md) | Draft | 20-minute moderated walk: lead search/research, CRM ownership and status, reviewed outreach, inbox reply, proposed/confirmed booking |
| [intake-template.md](intake-template.md) | Ready to use | Consented, sanitized observation log; each observation maps to a proposed feature/fix and the task card that owns it |
| [video-shot-list.md](video-shot-list.md) | Draft | V21's 2:50 shot list plus the honestly labeled fallback clip for provider latency |
| [social-post.md](social-post.md) | Draft, **not published** | One X/LinkedIn post tagging the four sponsors |

Rules that apply to everything here:

- Consent first. No observation, quote or screenshot is recorded or shared
  without the participant's explicit consent, given in the invitation and
  re-confirmed at the start of the session.
- Sanitized only. No real prospect names, real email addresses, message
  bodies, tokens or workspace internals leave this repository's private
  notes. Published material uses the controlled demo workspace only.
- No invented validation. If the trial does not happen, the evidence says so
  and names the blocker; it does not contain a testimonial.
- Controlled recipients only. The trial and the video use the pre-arranged
  controlled inbox, never a discovered real prospect.
