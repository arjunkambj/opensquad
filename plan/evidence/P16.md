## Contract changes

- `demo.tour` (public query): `{enabled:false}` when `OPENSQUAD_DEMO_TOUR`
  unset; else curated sanitized steps, `preparedData:true`, honest limits.
  Never reads workspace tables.
- `demo.executionStatus` (public query): flag states + caller's demo
  workspace id (null when signed out).
- `demo.optIn` (public mutation): `OPENSQUAD_DEMO_EXECUTION` required;
  authenticated; idempotent; creates an isolated `demoMode:true` workspace
  (`dailySendLimit 2`, `modelRunDailyLimit 3`, paused); refuses identities
  that already own a non-demo workspace. `demoMode` remains server-assigned
  only — no client or settings path can set/clear it.
- Send-boundary quotas already existed (`convex/sending.ts`: allowlist +
  `OPENSQUAD_DEMO_MAX_DAILY_SENDS` AND-ed with workspace limit under
  `demoMode`). No change needed there.
- Deploy script review: `static-hosting deploy` = build with prod
  `VITE_CONVEX_URL` → `convex deploy` → atomic manifest upload. Default
  `npm run build` replaced with `pnpm run build` so the served tree is
  exactly `pnpm build`'s `dist`.

## Routing proof (local site origin, catch-all live)

| Probe | Result |
|---|---|
| `GET /`, `/leads`, `/tour`, `/nonexistent-page` | 200 `index.html` — SPA + fallback |
| `GET /missing.js` | 404 — extensioned asset paths never fall back |
| `POST /worker/claim` (no auth) | 401 JSON `UNAUTHENTICATED` |
| `POST /worker/claim` (bogus token) | 401 JSON `invalid worker credential` |
| `GET /worker/claim`, `GET /worker/artifact` | 405 JSON — guard, not the SPA |
| `GET /agentmail/webhook` | 405 |
| `POST /agentmail/webhook` unsigned (secret set) | 401 `invalid signature` |
| `GET /firecrawl/webhook` | 405 |
| `POST /firecrawl/webhook` unsigned (secret set) | 401 `invalid signature` |
| `PUT /worker/claim` | 404 `No matching routes found` |
| `GET /assets/index-*.js` | 200 `application/javascript`, `max-age=31536000, immutable`, ETag, `nosniff` |
| `POST /agentmail/webhook` unsigned with NO secret | 500 (handler throws — fail closed) |

Conclusion: app routing cannot swallow `/worker/*` or webhook paths — exact
`(path, method)` routes beat the GET prefix catch-all, and the added GET 405
guards close the only remaining gap (a bare GET on a reserved path).
