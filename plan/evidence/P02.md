## Contract decisions

1. **`identityKey = identity.tokenIdentifier`** (`iss|sub`), per P01's verified
   provider shape. Membership/workspace rows never key on name/email.
2. **Anonymous-issuer rejection.** `requireUser` verifies
   `identity.issuer === https://api.hexclave.com/api/v1/projects/{VITE_HEXCLAVE_PROJECT_ID}`.
   Hexclave's second `customJwt` issuer (`projects-anonymous-users/{id}`) and
   any foreign issuer are rejected; `aud` is unbound so the exact `iss` match
   is the check. Missing env var fails closed. `getCurrent` returns `null`
   (not an error) for signed-out/anonymous callers.
3. **`ensureWorkspace` ≡ §5's proposed `bootstrap`.** Both names export the
   same idempotent mutation; the task card named it `ensureWorkspace`, §5
   proposes `bootstrap` — kept both so either reference resolves.
   Idempotency is keyed on the verified identity (one workspace per person via
   onboarding); check-then-insert inside the mutation is safe because Convex
   serializes transactions and retries index-range conflicts. `requestId` is
   accepted but intentionally not persisted (identity dedup subsumes it).
4. **NOT_FOUND for cross-workspace access** — a non-member or missing
   workspace produces the same error, so no other workspace's existence leaks
   (V02). FORBIDDEN is reserved for members holding an insufficient role.
5. **`exclusions` is `v.array(v.string())`** (bounded list), the natural shape
   for "excluded companies/segments"; P08 forms can map textarea lines.
6. **Capability IDs** (`allowedCapabilities`) use a new typed union in
   `lib/validators.ts`: `apollo.company_search`, `apollo.contact_enrichment`,
   `opensquad.web_research`, `opensquad.draft_compose`,
   `opensquad.reply_classify`. `HOST_CAPABILITY_POLICY` caps each template
   (scout/researcher/outreach); updates are intersected and out-of-policy IDs
   fail loudly. Apollo send/sequence, direct Firecrawl MCP and shell/network
   tools are absent by construction (§9). P07/P09 may refine the ID namespace.
7. **`sourcePlan` shape**: `{instruction, sources[], confirmedBy?,
   confirmedAt?, confirmedBriefVersion?}`. `instruction` is the original
   operator text kept separately from the typed interpretation; the
   `confirmed*` triple is stamped once by `confirmSourcePlan` and immutable —
   reconfirmation or non-draft confirmation returns `CONFLICT`.
8. **Typed source filters**: `apollo` (locations, categories, employeeCount
   range, optional `maxResults`), `yc` (batch, categories, locations),
   `trustmrr` (explicit metric/currency/period + optional min/max bounds).
   `ENABLED_SOURCES = ["apollo"]` — confirming a plan containing yc/trustmrr
   fails with "its extraction gate is still pending" (per plan §1 gate).
9. **Campaign transitions**: `draft→active|completed`,
   `active→paused|completed`, `paused→active|completed`, `completed` terminal.
   Reaching `active` requires a confirmed source plan. Same-state `setState`
   is an idempotent no-op; illegal transitions return `CONFLICT`.
10. **Version fields**: `campaigns.briefVersion` (bound into
    `confirmedBriefVersion`; no brief-edit API exists yet — adding one must
    bump it), `businessProfiles.version`, `employees.instructionVersion`,
    `workspaces.policyVersion`. `expectedVersion`-style args return `CONFLICT`
    on mismatch. Membership rows are unversioned per contract (no version
    field) — guarded by the last-owner invariant instead.
11. **Defaults on bootstrap**: `automationState: "paused"` +
    `pauseReason: "onboarding_pending"` (conservative until onboarding
    confirms policy), `dailySendLimit: 10`, `sendWindow` Mon–Fri 09:00–17:00,
    `policyVersion: 1`, `demoMode: false` (server-only per §9; no client arg
    can set it), `timezone: "UTC"` unless supplied.
12. **`workspaces.update`/`setSendingPolicy`/`setAutomationState` are
    owner-only** (name/timezone + sending policy are §3.1 owner column);
    `businessProfiles.update`, `employees.update`, `campaigns.*` mutations use
    owner-or-operator; reads use any active member. No public join mutation,
    no invitation email side effects.
13. **`campaigns.list` returns `{items, hasMore}`** via indexed `take(limit+1)`
    instead of a bare array, preserving the §5 "explicit more" rule.
